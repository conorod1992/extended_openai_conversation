# Hybrid cold-cache refill follow-up

Cooldown ships independently of cold-cache latency. Current preparation holds the request reader/maintenance lease while generating every missing vector in the authorized scopes. At 10,000 facts and batches of 64 that means 157 corpus calls plus a query embedding call. Automatic bundle reuse already avoids a new search on every continuing turn. Failed durable fact saves normally reconcile vectors; this change does not replace that rollback mechanism.

A bounded foreground batch plus background drain needs additional lifecycle machinery. PersistentMemory currently has no owned semantic warming task, while its provider callback closes over an entity and records Usage against the active request context. Simply creating an asyncio task could inherit a completed turn, continue beyond the reader lease, or recreate stores after deletion/restore. Existing Temporary Memory/Usage prune ownership is specific to those managers and cannot own this job unchanged.

Implement one manager-owned drain, integrated with the existing maintenance gate and unload/delete/restore coordinators. Start it only for scopes authorized by an actual search; coalesce scopes without crossing owners. Give it a detached request context and explicit Usage ownership. Cancel and await it before relevant configuration replacement or destructive maintenance, preserving settlement of native writes already owned. Fence results by runtime generation, provider/model/space and record fingerprint. Expose warming/ready/failure status per relevant scope and serve lexical results until every relevant vector is ready. Test concurrent scope admission, configuration rotation, expiry/backoff, unload, deletion, restore, Usage context isolation and write settlement in genuine Home Assistant acceptance tests.

Do not require hundreds of future searches to warm a large corpus, silently disable semantic retrieval, or score a partial cache incidentally. Until that owned drain is available, the existing complete foreground preparation remains, including its cold latency.
