Extended OpenAI Conversation (Responses) is a Home Assistant conversation integration for OpenAI and compatible providers. It combines Home Assistant entity and service access with modern model APIs, Web Search, memory, voice features, custom Function Tools, privacy controls, and a dedicated management interface.

The project began as a fork of `jekalmin/extended_openai_conversation` and has since diverged substantially while retaining the original project's flexible custom-function framework.

You can start with a simple conversation agent and add advanced features only when you need them.

## Permissions and privacy

A useful rule of thumb is that three things must all allow an action: the entity must be available to Assist, the Home Assistant user must have permission, and any Extended OpenAI restrictions must also allow it.

Guest Mode and other Extended OpenAI policies can make access more restrictive, but they cannot grant permission that Home Assistant has denied. For shared voice devices, configure [Voice Identity](/features/voice-identity) deliberately so personal memories and retained conversations are associated with the intended user.

## Reliability

The integration is validated with layered automated testing rather than only isolated unit tests. The suite includes genuine Home Assistant acceptance tests, browser-to-Home-Assistant tests, upgrade testing from a previously published release to the candidate build, and selected cross-browser coverage.

No automated suite can guarantee every provider or custom setup, but the project deliberately exercises important real Home Assistant boundaries such as authorization, entity/service changes, backup restoration, conversation ownership, and delayed execution.

## OpenAI API billing

A ChatGPT subscription is not an OpenAI API subscription. This integration sends requests to the configured API provider, and API usage may be billed separately by that provider. Keep provider credentials private.
