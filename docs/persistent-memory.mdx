---
title: "Persistent memory"
description: "Keep durable personal and household facts available across conversations"
---

Persistent memory stores concise facts, not transcripts. It is off by default and supports **Manual** (explicit saves only) and **Automatic** (stable proactive saves) modes.

## Conversation context

**Automatically include memories** accepts `0–10` (default `3`). The opening message selects one fixed bundle for the logical conversation. Later turns reload those IDs so edits and deletions are reflected, but do not rerank automatically. Set `0` for tool-only use; `memory_search` remains available if the topic changes.

## Retrieval

**Lightweight lexical** is local and dependency-free. It combines BM25-style IDF/term-frequency scoring with phrases, normalization, conservative typo/prefix handling, and category, subject, and key bonuses. Importance (`low`, `normal`, `high`) is a bounded multiplier after a relevance threshold, so an unrelated high-importance record is excluded.

**Hybrid semantic** adds embeddings and local cosine similarity without an extra LLM/classifier call or a vector database. It makes one query-embedding request when a conversation starts and reuses stored memory embeddings. Unsupported providers and embedding failures fall back to lexical. Embeddings are not exposed in prompts, tools, diagnostics, or backups.

## Metadata and tools

Optional `subject` and normalized canonical `key` fields identify a logical fact. Keys are unique per owner scope. `valid_from` records when a fact became true; `last_confirmed_at` is refreshed on creation, confirmation, and meaningful updates. Memories do not automatically expire.

Prefer `memory_upsert`: exact keys update, duplicates confirm, uncertain related facts return `needs_resolution`, and unrelated facts create a record. `memory_add`, search, list, update, and delete remain available for compatibility.

## Scope and privacy

Authenticated conversations read their own personal memory plus enabled shared-household memory. Shared conversations read household only; unretained conversations retain nothing. Writes default to personal and require a deliberate `household` selector for shared facts. Automatic household writes require shared Automatic mode. No user can read or manipulate another user's personal scope.

The management panel supports text, category, importance, and scope filtering and keeps advanced metadata visually secondary. Versioned storage and full backup/restore preserve all record metadata; embeddings are regenerated after restore. Retrieved text is untrusted background data and cannot supply instructions or authority. Persistent memory is not a secrets manager.
